==================================================
02. C++ HISTORY AND FEATURES
==================================================

1. HISTORY OF C++

- C++ was developed by Bjarne Stroustrup.
- Development started in 1979 at Bell Labs.
- It was originally called "C with Classes".
- In 1983, it was renamed to "C++".
- C++ was developed as an extension of the C language.


2. FEATURES OF C++

1. Simple and Powerful
   - Provides a wide range of programming features.

2. Object-Oriented
   - Supports Class, Object, Inheritance, Polymorphism, etc.

3. High Performance
   - Compiled language with fast execution.

4. Platform Independent
   - C++ programs can be compiled on different platforms.

5. Memory Management
   - Provides direct control over memory using pointers
     and dynamic memory allocation.

Syntax:
int* ptr = new int;


6. Standard Template Library (STL)
   - Provides ready-to-use data structures and algorithms.

Example:
std::vector<int> numbers;


7. Multi-Paradigm
   - Supports Procedural, Object-Oriented and Generic
     Programming.

8. Case Sensitive
   - Uppercase and lowercase letters are different.

Example:
int age;
int Age;

Both are different variables.

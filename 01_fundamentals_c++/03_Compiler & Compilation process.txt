==================================================
03. COMPILER & COMPILATION PROCESS
==================================================

1. COMPILER

A Compiler is a system software that converts a C++ source
code into machine code that the computer can execute.

Source Code  ->  Compiler  ->  Machine Code


2. COMPILATION PROCESS

The C++ compilation process mainly consists of these steps:

1. Preprocessing
   - Processes header files and preprocessor directives.
   - Example: #include <iostream>

2. Compilation
   - Converts preprocessed C++ code into assembly code.

3. Assembly
   - Converts assembly code into object code.

4. Linking
   - Combines object code with required libraries.
   - Produces the final executable file.


3. COMPLETE PROCESS

C++ Source Code (.cpp)
        |
        v
   Preprocessor
        |
        v
   Compiler
        |
        v
   Assembly Code
        |
        v
   Assembler
        |
        v
   Object Code (.obj / .o)
        |
        v
     Linker
        |
        v
Executable File (.exe)


4. EXAMPLE

File:
main.cpp

Command:
g++ main.cpp -o main

Here:
g++       -> C++ compiler
main.cpp  -> Source file
-o main   -> Name of output executable

Output:
main.exe

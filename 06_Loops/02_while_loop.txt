WHILE LOOP

Definition:

A while loop is used to repeatedly execute a block of code
as long as a specified condition is true.

It is useful when the number of repetitions is not known in advance.


Syntax:

    while(condition)
    {
        // statements
    }


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        int i = 1;

        while(i <= 5)
        {
            cout << i << endl;
            i++;
        }

        return 0;
    }


Output:

    1
    2
    3
    4
    5


Here:

    i = 1       → initialization
    i <= 5      → condition
    i++         → increases i by 1


How while Loop Works:

    Step 1 → Initialize the variable
    Step 2 → Check the condition
    Step 3 → Execute the statements
    Step 4 → Update the variable
    Step 5 → Repeat until the condition becomes false


Key Points:

    1. while loop checks the condition before execution.
    2. It may execute zero or more times.
    3. The condition must eventually become false to stop the loop.
    4. It is useful when the number of iterations is not known.


In simple words:

    while loop = condition true rehne tak code ko repeat karta hai.


Exam Answer:

A while loop is a control statement that repeatedly executes
a block of statements as long as the given condition is true.

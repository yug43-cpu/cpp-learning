INCREMENT & DECREMENT

Definition:

Increment operator is used to increase the value of a variable by 1.
Decrement operator is used to decrease the value of a variable by 1.


Operators:

    Operator    Meaning
    -------------------------
    ++          Increment by 1
    --          Decrement by 1


Types:

    Type          Example
    -------------------------
    Pre-increment   ++a
    Post-increment  a++
    Pre-decrement   --a
    Post-decrement  a--


Example:

    int a = 5;

    a++;
    cout << a;


Output:

    6


Here:

    a++ = increases a by 1
    5 + 1 = 6


Example:

    int a = 5;

    a--;
    cout << a;


Output:

    4


Here:

    a-- = decreases a by 1
    5 - 1 = 4


Pre and Post:

    Pre-increment:
        ++a
        First increases the value, then uses it.

    Post-increment:
        a++
        First uses the value, then increases it.

    Pre-decrement:
        --a
        First decreases the value, then uses it.

    Post-decrement:
        a--
        First uses the value, then decreases it.


Key Points:

    1. ++ increases the value by 1.
    2. -- decreases the value by 1.
    3. ++a and a++ are increment operators.
    4. --a and a-- are decrement operators.


In simple words:

    ++ = value ko 1 se badhana
    -- = value ko 1 se ghatana


Exam Answer:

Increment operator (++) increases the value of a variable by 1,
while decrement operator (--) decreases the value of a variable by 1.

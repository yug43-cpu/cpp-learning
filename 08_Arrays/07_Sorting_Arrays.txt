SORTING ARRAYS

Definition:

Sorting an array means arranging the elements of an array in a
specific order.

The two common orders are:
    Ascending Order  = smallest to largest
    Descending Order = largest to smallest


Common Sorting Methods:

    Method              Description
    -----------------------------------------------
    Bubble Sort         Compares and swaps elements
    Selection Sort      Selects the smallest/largest element
    Insertion Sort      Inserts elements in the correct position


Bubble Sort:

Bubble sort repeatedly compares adjacent elements and swaps them
if they are in the wrong order.


Syntax:

    for(int i = 0; i < size - 1; i++)
    {
        for(int j = 0; j < size - i - 1; j++)
        {
            if(array[j] > array[j + 1])
            {
                // swap elements
            }
        }
    }


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        int a[5] = {50, 20, 40, 10, 30};

        for(int i = 0; i < 5 - 1; i++)
        {
            for(int j = 0; j < 5 - i - 1; j++)
            {
                if(a[j] > a[j + 1])
                {
                    int temp = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = temp;
                }
            }
        }

        cout << "Sorted Array: ";

        for(int i = 0; i < 5; i++)
        {
            cout << a[i] << " ";
        }

        return 0;
    }


Output:

    Sorted Array: 10 20 30 40 50


Here:

    a = array name
    i = controls the number of passes
    j = compares adjacent elements
    a[j] and a[j + 1] = adjacent elements
    temp = temporary variable used for swapping


Ascending Order:

    10 20 30 40 50
    Smallest → Largest


Descending Order:

    50 40 30 20 10
    Largest → Smallest

    For descending order, use:

        if(a[j] < a[j + 1])


Key Points:

    1. Sorting arranges array elements in a specific order.
    2. Ascending order arranges elements from smallest to largest.
    3. Descending order arranges elements from largest to smallest.
    4. Bubble sort compares adjacent elements and swaps them.
    5. A temporary variable can be used for swapping.


In simple words:

    Sorting Array = array ke elements ko proper order me arrange karna.


Exam Answer:

Sorting an array is the process of arranging its elements in a
specific order, such as ascending or descending order.

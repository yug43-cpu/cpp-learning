1D ARRAYS

Definition:

A 1D (one-dimensional) array is a collection of elements of the
same data type stored in a single row.

Each element is accessed using an index number.
The index starts from 0.


Syntax:

    data_type array_name[size];


Example:

    int marks[5] = {80, 75, 90, 85, 70};


Here:

    int = data type
    marks = array name
    5 = size of the array
    {80, 75, 90, 85, 70} = array elements

    Index:

        0    1    2    3    4
       -------------------------
       80   75   90   85   70


Accessing Array Elements:

    cout << marks[0];
    cout << marks[2];


Output:

    80
    90


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        int numbers[5] = {10, 20, 30, 40, 50};

        for(int i = 0; i < 5; i++)
        {
            cout << numbers[i] << endl;
        }

        return 0;
    }


Output:

    10
    20
    30
    40
    50


Key Points:

    1. A 1D array stores elements in a single row.
    2. All elements must have the same data type.
    3. Array indexing starts from 0.
    4. The last index is size - 1.
    5. Elements are accessed using the index number.


In simple words:

    1D Array = same type ke multiple values ko ek single list
    me store karne ke liye use hota hai.


Exam Answer:

A one-dimensional array is a collection of elements of the same
data type stored in a single row and accessed using index numbers.
The index of an array starts from 0.

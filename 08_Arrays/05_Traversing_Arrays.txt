TRAVERSING ARRAYS

Definition:

Array traversing means visiting and accessing each element of an
array one by one.

A loop is commonly used to traverse an array.


Syntax:

    for(int i = 0; i < size; i++)
    {
        cout << array_name[i];
    }


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        int numbers[5] = {10, 20, 30, 40, 50};

        for(int i = 0; i < 5; i++)
        {
            cout << numbers[i] << " ";
        }

        return 0;
    }


Output:

    10 20 30 40 50


Here:

    numbers = array name
    5 = number of elements
    i = index variable
    numbers[i] = accesses each element
    for loop = visits each element one by one


Array Traversing:

    Index       Element
    -------------------
    0           10
    1           20
    2           30
    3           40
    4           50


Key Points:

    1. Traversing means accessing each array element one by one.
    2. A loop is commonly used for array traversal.
    3. Array indexing starts from 0.
    4. The last index is size - 1.


In simple words:

    Array Traversing = array ke har element ko ek-ek karke access karna.


Exam Answer:

Array traversing is the process of accessing or visiting each
element of an array one by one, usually with the help of a loop.

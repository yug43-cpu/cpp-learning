CHARACTER ARRAYS

Definition:

A character array is an array used to store a sequence of characters.
It is commonly used to store text or strings.

A character array ends with a special null character '\0'.


Syntax:

    char array_name[size];


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        char name[6] = {'Y', 'u', 'g', '\0'};

        cout << name;

        return 0;
    }


Output:

    Yug


Here:

    char = data type used to store characters
    name = character array
    {'Y', 'u', 'g', '\0'} = characters stored in the array
    '\0' = null character that marks the end of the string


Character Array with String:

    char name[] = "Yug";

    cout << name;


Output:

    Yug


Here:

    char name[] = "Yug";

    The compiler automatically adds '\0' at the end.

    Memory:
        Y    u    g    \0


Common Character Array Operations:

    Operation           Example
    -----------------------------------------------
    Declare array       char name[20];
    Initialize          char name[] = "Yug";
    Display             cout << name;
    Access character    name[0]


Example of Accessing Characters:

    #include <iostream>
    using namespace std;

    int main()
    {
        char name[] = "Yug";

        cout << name[0] << endl;
        cout << name[1] << endl;
        cout << name[2];

        return 0;
    }


Output:

    Y
    u
    g


Key Points:

    1. Character arrays are used to store characters or text.
    2. The data type used is char.
    3. Character arrays use indexes starting from 0.
    4. A string stored in a character array ends with '\0'.
    5. char name[] = "Yug"; automatically adds '\0'.


In simple words:

    Character Array = characters ko array ke form me store karna,
    mainly text or string store karne ke liye.


Exam Answer:

A character array is an array of characters used to store a sequence
of characters or a string. A string stored in a character array is
terminated by a null character '\0'.

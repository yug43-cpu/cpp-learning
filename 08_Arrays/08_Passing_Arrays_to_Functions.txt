PASSING ARRAYS TO FUNCTIONS

Definition:

Passing arrays to functions means sending an array as an argument
to a function so that the function can access and process its elements.

When an array is passed to a function, its elements can be accessed
inside the function.


Syntax:

    return_type function_name(data_type array_name[], int size)
    {
        // statements
    }


Example:

    #include <iostream>
    using namespace std;

    void display(int a[], int size)
    {
        for(int i = 0; i < size; i++)
        {
            cout << a[i] << " ";
        }
    }

    int main()
    {
        int numbers[5] = {10, 20, 30, 40, 50};

        display(numbers, 5);

        return 0;
    }


Output:

    10 20 30 40 50


Here:

    numbers = array passed to the function
    a[] = parameter that receives the array
    5 = size of the array
    display() = function used to display array elements
    a[i] = accesses each element inside the function


How It Works:

    1. An array is created in the main() function.
    2. The array name is passed to the function.
    3. The function receives the array through a parameter.
    4. The function can access each element using its index.


Example:

    display(numbers, 5);

    numbers = array
    5 = number of elements


Key Points:

    1. Arrays can be passed to functions as arguments.
    2. The array name is passed to the function.
    3. The size of the array is usually passed separately.
    4. The function can access array elements using indexes.
    5. Changes made to array elements inside the function can affect
       the original array.


In simple words:

    Passing Arrays to Functions = array ko function ke andar bhejkar
    uske elements par operation karna.


Exam Answer:

Passing an array to a function means passing an array as an argument
to a function so that the function can access and process its
elements.

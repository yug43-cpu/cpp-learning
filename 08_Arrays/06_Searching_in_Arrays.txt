SEARCHING IN ARRAYS

Definition:

Searching in an array means finding a particular element or value
from the array.

One common method of searching is Linear Search.


Linear Search:

Linear search checks each element of the array one by one until
the required element is found.


Syntax:

    for(int i = 0; i < size; i++)
    {
        if(array_name[i] == value)
        {
            // element found
        }
    }


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        int numbers[5] = {10, 20, 30, 40, 50};
        int search = 30;
        int position = -1;

        for(int i = 0; i < 5; i++)
        {
            if(numbers[i] == search)
            {
                position = i;
                break;
            }
        }

        if(position != -1)
        {
            cout << "Element found at index " << position;
        }
        else
        {
            cout << "Element not found";
        }

        return 0;
    }


Output:

    Element found at index 2


Here:

    numbers = array
    search = value to be searched
    i = index variable
    numbers[i] = current array element
    position = stores the index of the found element
    break = stops the loop when the element is found


Searching Result:

    Search Value       30
    Found               Yes
    Index               2


Key Points:

    1. Searching is used to find an element in an array.
    2. Linear search checks elements one by one.
    3. Array indexing starts from 0.
    4. If the element is not found, position remains -1.
    5. break can be used to stop searching after finding the element.


In simple words:

    Searching in Array = array ke andar kisi particular value ko
    find karna.


Exam Answer:

Searching in an array is the process of finding a particular
element or value from an array. Linear search checks each element
one by one until the required element is found.
